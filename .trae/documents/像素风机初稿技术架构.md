# 像素风机甲对战游戏 - 技术架构文档

## 1. 技术栈选择

### 前端技术
- **核心框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式方案**: Tailwind CSS + 自定义像素风格CSS
- **游戏引擎**: 原生HTML5 Canvas + 自定义游戏循环
- **动画方案**: CSS Animations + requestAnimationFrame

### 架构模式
采用模块化组件架构，便于维护和扩展：
- 纯前端SPA（Single Page Application）
- 状态管理：React Hooks（useState, useReducer, useContext）
- 游戏状态集中管理，组件化UI渲染

## 3. 核心类设计

游戏引擎负责整体游戏循环和状态管理：

```typescript

  + render(): void
```

### 3.2 Player（玩家类）

玩家类封装机甲的状态和行为：


### 3.3 Collision（碰撞检测）

碰撞检测系统使用AABB（轴对齐边界框）算法：

```typescript
class CollisionSystem {
```


## 6. 渲染流程

游戏采用双缓冲渲染减少闪烁：

1. **清除画布**: 绘制背景层
2. **绘制地面**: 金属地板平台
3. **绘制装饰**: 背景装饰元素
4. **绘制机甲**: 根据当前动画帧渲染
5. **绘制特效**: 攻击光效、防御盾
6. **绘制UI**: 血量条、能量条、游戏信息
7. **绘制粒子**: 受伤数字、特效粒子

### 7.2 精灵绘制

机甲使用程序化生成的像素精灵，无需外部图片：

```typescript
function drawMech(
  ctx: CanvasRenderingContext2D,
  x: number,
  y: number,
  color: string,
  accent: string,
  animation: string
) {
  // 绘制机甲身体
  ctx.fillStyle = color
  ctx.fillRect(x, y, 32, 48)
  // 绘制细节
  ctx.fillStyle = accent
  ctx.fillRect(x + 4, y + 4, 8, 8) // 眼睛
  // 根据动画状态调整绘制
}
```

## 8. 性能优化

- **对象池**: 粒子效果使用对象池复用
- **脏矩形渲染**: 只重绘变化区域（可选）
- **requestAnimationFrame**: 浏览器原生帧同步
- **避免GC压力**: 预分配游戏对象，避免运行时创建
