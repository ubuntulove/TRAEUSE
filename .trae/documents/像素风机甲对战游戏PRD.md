# 像素风机甲对战游戏 - 产品需求文档

## 1. 产品概述

一款复古像素风格的机甲对战小游戏，两位玩家各操控一台机甲进行1v1对战。游戏采用经典街机格斗游戏的操作方式，玩家1使用WASD移动和攻击，玩家2使用方向键操作。游戏目标是击败对手的机甲，最后存活的一方获胜。

核心玩法强调操作的爽快感和策略性，通过移动、攻击、防御的组合创造多样的战斗体验。视觉风格采用80年代街机游戏的像素美学，配合现代的前端技术实现流畅的动画效果。

## 2. 核心功能

### 2.1 机甲角色设计

游戏包含两台风格迥异的像素风机甲：

| 机甲 | 名称 | 特点 | 颜色主题 |
|------|------|------|----------|
| 机甲1 | 烈焰战将 | 高攻击输出，中等防御 | 橙红色系 |
| 机甲2 | 寒冰守卫 | 高防御能力，中等攻击 | 蓝白色系 |

每台机甲具备以下属性：
- **生命值 (HP)**: 100点
- **攻击力 (ATK)**: 10-15点伤害
- **防御力 (DEF)**: 减免20%伤害
- **移动速度**: 5像素/帧
- **攻击范围**: 近距离挥砍

### 2.2 操作控制

#### 玩家1 - 烈焰战将
| 按键 | 功能 |
|------|------|
| W | 跳跃 |
| A | 向左移动 |
| D | 向右移动 |
| J | 普通攻击 |
| K | 防御姿态 |
| L | 特殊攻击（消耗能量） |

#### 玩家2 - 寒冰守卫
| 按键 | 功能 |
|------|------|
| ↑ | 跳跃 |
| ← | 向左移动 |
| → | 向右移动 |
| Numpad 1 | 普通攻击 |
| Numpad 2 | 防御姿态 |
| Numpad 3 | 特殊攻击（消耗能量） |

### 2.3 游戏机制

#### 攻击系统
- **普通攻击**: 快速挥砍，造成10-15点伤害，冷却时间500ms
- **特殊攻击**: 强力斩击，造成25-30点伤害，消耗30%能量条，能量条每5秒恢复10%
- **防御姿态**: 减少受到伤害的50%，但无法移动和攻击

#### 胜负判定
- 当任意一方生命值降至0时，游戏结束
- 显示胜利者动画和"胜利"提示
- 提供"再来一局"按钮重新开始

### 2.4 场景设计

游戏场景采用简单的工业风格战场：
- 背景层：深色工业厂房，带有锈蚀金属纹理
- 地面：金属地板平台，带有防滑纹理
- 装饰：散落的机械零件、蒸汽管道背景
- 整体氛围：昏暗的工厂灯光明暗交错

## 3. 用户界面设计

### 3.1 整体视觉风格

采用80年代街机游戏的像素美学：
- **分辨率**: 模拟低分辨率渲染（320x180像素），后放大至全屏
- **调色板**: 限制在32色以内的复古色板
- **动画**: 逐帧像素动画，8-12帧每秒
- **特效**: 简单的粒子效果（攻击火花、防御光盾）

### 3.3 色彩方案

- **主色调**: #1a1a2e（深蓝黑背景）
- **地面/平台**: #4a4a4a（工业灰）
- **P1机甲**: #ff6b35（橙红） + #f7c59f（浅橙）
- **P2机甲**: #4ecdc4（青蓝） + #a8e6cf（浅绿）
- **HP条**: #ff6b6b（红色）→ #ffd93d（黄色）→ #6bcb77（绿色）
- **能量条**: #9d4edd（紫色）
- **UI文字**: #ffffff（白色）+ #ffd93d（高亮金）

## 4. 动画与特效

### 4.1 机甲动画

每台机甲包含以下像素动画帧：
- **待机**: 轻微的呼吸起伏，4帧循环
- **行走**: 左右交替脚步，6帧循环
- **跳跃**: 上升-空中-下落，3帧
- **攻击**: 挥砍动作，4帧
- **防御**: 举起护盾，2帧
- **受伤**: 闪烁+后退，3帧
- **胜利**: 举起双臂欢呼，6帧
- **失败**: 倒地，4帧

### 4.2 特效设计

- **攻击特效**: 橙红色（玩家1）或蓝白色（玩家2）的斩击光效
- **防御特效**: 半透明能量盾笼罩机甲
- **受伤特效**: 白色闪烁 + 数字伤害飘字
- **胜利特效**: 金色粒子喷射 + "VICTORY"大字

## 5. 音效设计（可选增强）

游戏音效采用8-bit风格：
- 攻击音效：短促的金属斩击声
- 防御音效：能量盾激活的嗡嗡声
- 受伤音效：金属撞击的沉闷声
- 胜利音效：欢快的8-bit旋律
- BGM：节奏感强的电子风格背景音乐

## 6. 技术约束

- 纯前端实现，无需后端服务
- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 响应式设计，适配不同屏幕尺寸
- 目标帧率：60 FPS
- 加载时间：< 3秒
