# NEON SNAKE — 霓虹贪吃蛇

一个用纯原生 HTML5 Canvas + JavaScript 实现的霓虹风贪吃蛇，零依赖、零构建，打开即玩。
本项目用来展示完整的游戏工程能力：状态机、固定时间步游戏循环、实体系统、
粒子/飘字特效、程序化音效合成、道具机制、难度递增与本地存档。

## 特性

- **完整玩法循环**：开始 → 游玩 → 暂停 → 死亡 → 重开，状态机驱动
- **4 种食物**：普通(+10) / 金币(+50) / 减速道具 / 双倍分数道具，加权随机生成
- **难度递增**：每吃若干个食物升级，蛇速递增，最快 0.05s/格
- **平滑渲染**：固定时间步推进逻辑 + 渲染插值，蛇身丝滑移动而非跳格
- **粒子系统**：吃食物爆炸、升级金环、死亡碎裂（对象池化）
- **飘字反馈**：拾取时显示 `+10` `LV 3` 等飘字
- **程序化音效**：Web Audio API 振荡器实时合成，无任何音频文件，懒加载 + 静音开关
- **本地存档**：最高分 + 静音偏好持久化（localStorage）
- **响应式 + 触屏**：桌面键盘 / 移动端滑动 + 虚拟方向键
- **霓虹视觉**：渐变发光、脉动食物、状态条（双倍/减速剩余时间）

## 操作

| 操作 | 按键 |
| --- | --- |

| 暂停 | 空格 |

## 运行

无需构建。任选一种：

```bash
# 方式 1：直接用浏览器打开 index.html

# 方式 2：本地起一个静态服务器（推荐，音效需用户手势触发）
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 项目结构

```
.
├── index.html        # 页面骨架与脚本加载顺序
├── css/style.css     # 霓虹主题样式
└── js/
    ├── storage.js    # 本地存档（最高分 / 静音）
    ├── audio.js      # Web Audio 程序化音效合成器
    ├── input.js      # 键盘 + 触摸滑动 + 虚拟方向键，防反向自杀
    ├── entities.js   # Snake / Food / ParticleSystem / FloatingText
    ├── ui.js         # 覆盖层（开始/暂停/结束）与 HUD 控制
    ├── game.js       # 核心循环、状态机、渲染、难度递增
    └── main.js       # 入口：装配各模块并启动主循环
```

模块按依赖顺序加载（底层 → 实体 → 系统 → 入口），各模块挂在 `window.*` 命名空间下，
避免全局污染。`window.__game` 暴露游戏实例便于调试。

## 技术要点

- **固定时间步 + 渲染插值**：逻辑以 `tickInterval` 离散推进，渲染用 `tickAccumulator/interval`
  作为插值进度，做到"逻辑稳定、画面丝滑"。
- **防反向输入**：`Input.request` 与 `Snake.setDirection` 双重过滤 180° 急转，避免单帧自杀。
- **状态机**：`IDLE / PLAYING / PAUSED / OVER`，暂停时仍更新粒子避免画面卡死。
- **对象池粒子**：`ParticleSystem` 容量上限 + 复用，避免长时间运行的内存增长。
- **懒加载 AudioContext**：遵守浏览器策略，在首次用户手势时创建并 resume。
- **纯过程化美术**：圆角格子 + 径向渐变发光圈 + 高光 + 脉动，无需任何图片资源。
